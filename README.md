
# Hytte Monitoring

Hytte Monitoring is a student project focused on developing a remote cabin monitoring system using UML and specification-driven AI development.

This repository is my independent development version of the original group project, used for experimentation, testing, and further implementation.

[![Website](https://img.shields.io/badge/WEBSITE-VISIT%20HYTTE%20MONITORING-5A9F58?style=for-the-badge&labelColor=555555&logo=googlechrome&logoColor=white)](https://kevanrc2-oss.github.io/hytte-monitoring-lab/)

## Layout

- `website/` — the static site (HTML, CSS, images)
- `model/` — UML diagrams of the system
- `research/` — background notes and findings
- `specs/` — written specifications
- `plans/` — implementation plans
